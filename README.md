# Meridian Hospital — AI RCM & Predictive Bed Allocation POC

A working proof-of-concept prototype demonstrating:
- **Module A: AI Revenue Cycle Management** — claim risk scoring, validation, revenue leakage detection
- **Module B: Predictive Bed Allocation** — real-time occupancy + AI surge forecasting

> ⚠️ Demo/POC environment only — uses synthetic data. No real HIS/EMR/insurance integrations.

---

## Quick Start

### Frontend (runs standalone — no backend needed)

```bash
cd frontend
npm install
npm run dev
```

Opens at: http://localhost:5173

**Login credentials:**
| Role | Username | Password |
|------|----------|----------|
| Admin | `admin` | `admin` |
| Doctor | `doc1` | `doc1` |

After login as `admin`, navigate to:
- **AI Module Overview** → full combined summary
- **Revenue Cycle** → RCM dashboard, Claims list, Claim detail
- **Bed Allocation** → Bed dashboard, Forecast

---

### Backend (optional — frontend falls back to mock data automatically)

```bash
cd backend

# 1. Create virtual environment
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS/Linux

# 2. Install dependencies
pip install -r requirements.txt

# 3. Seed the database (generates hospital.db)
python seed_data.py

# 4. Start the API server
uvicorn main:app --reload
```

API available at: http://localhost:8000  
Interactive docs: http://localhost:8000/docs

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/claims` | Paginated claims list (filterable) |
| GET | `/api/claims/{id}` | Full claim detail |
| GET | `/api/claims/{id}/risk` | Risk analysis with explainability |
| PATCH | `/api/claims/{id}/review` | Toggle reviewed status |
| GET | `/api/dashboard/rcm` | RCM KPI aggregates + chart data |
| GET | `/api/beds` | Current bed occupancy |
| GET | `/api/beds/forecast?horizon=24h` | Demand forecast (6h/12h/24h/7d) |
| GET | `/api/admissions/forecast` | Multi-horizon dept forecast |
| GET | `/api/dashboard/beds` | Bed allocation KPIs + trend |
| GET | `/health` | Service health check |

## Demo Features

### Role Switcher
The sidebar shows a **Demo Persona** panel at the bottom (when logged in as admin). Switch between:
- **Hospital Administrator** — full view
- **Billing Executive** — Revenue Cycle emphasized
- **Bed Manager** — Bed Allocation emphasized

### Explainability ("Why?" Panels)
Every risk score and forecast shows a **"Why this score?"** expandable panel listing the contributing factors — demonstrating the human-in-the-loop principle.

### AI Label
All AI-generated outputs are labeled with a subtle `AI-generated · human review required` badge.

### Offline Mode
If the Python backend is not running, the frontend automatically falls back to deterministic in-memory synthetic data. The demo works identically without any backend.
